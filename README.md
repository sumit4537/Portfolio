# 🚀 Sumit Kumar Sharma — Developer Portfolio

A modern, fully responsive personal portfolio website built with vanilla HTML, CSS, and JavaScript. Designed to showcase cloud/infrastructure projects, technical skills, and software development experience to recruiters and potential employers.

## ✨ Features

- **Fully Responsive** — Optimized for mobile, tablet, and desktop viewports with a mobile-first approach
- **Project Showcase** — Featured cards with live demo links and GitHub source code
- **Skills & Tools** — Categorized breakdown of cloud platforms, networking tools, programming languages, and developer tools
- **Contact Section** — Clean, minimal contact form for recruiters and collaboration inquiries
- **Zero Dependencies** — Built entirely with core web technologies; no frameworks or package manager required
- **Fast Load Times** — Lightweight codebase with no unnecessary overhead
- **Smooth Animations** — Subtle scroll-triggered transitions and interactive UI elements

## 🚀 Getting Started

### View Locally

No build step or package manager needed:

```bash
# 1. Clone the repository
git clone https://github.com/sumit4537/Portfolio.git

# 2. Open the project
cd Portfolio

# 3. Open index.html in your browser
open index.html        # macOS
start index.html       # Windows
xdg-open index.html   # Linux
```

Or just drag `index.html` into any browser.

### Deploy to GitHub Pages (Free Hosting)

1. Push your code to a GitHub repository
2. Go to **Settings → Pages**
3. Set **Source** to `main` branch, `/ (root)`
4. Click **Save** — your site will be live at `https://sumit4537.github.io/Portfolio/`
