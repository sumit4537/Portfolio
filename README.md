# 🚀 Personal Portfolio | Sumit

A modern, sleek, and fully responsive developer portfolio built to showcase web projects, technical skills, and software development experience.

![Status](https://img.shields.io/badge/Status-Active-brightgreen?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)

---

## ✨ Features

* **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
* **Featured Projects:** Showcases interactive web applications (including tools like Embrod Photo Studio) with direct links to live demos and GitHub source code.
* **Skills & Tools Showcase:** Highlighted breakdown of frontend, backend, and developer tools.
* **Contact Integration:** Clean contact section for client inquiries and collaboration opportunities.
* **Fast & Lightweight:** Built using core web technologies without heavy framework overhead for minimal load times.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, JavaScript (ES6+)
* **Styling:** CSS3, Glassmorphism UI, CSS Grid/Flexbox
* **Icons & Fonts:** FontAwesome 6, Google Fonts
* **Hosting:** GitHub Pages
